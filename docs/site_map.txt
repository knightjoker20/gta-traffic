## Public Pages (Current)

```text
/index.html
└── Main Workspace
    ├── Popgroups Editor
    │   ├── XML / YMT import
    │   ├── group list editor
    │   ├── quick clear tools
    │   └── cloud save / open
    ├── Pack Tracker
    │   ├── add / remove vehicles from packs
    │   └── cloud sync
    ├── Pack DB Builder
    │   ├── normal mod/add-on pack mode
    │   └── GTA DLC Reference mode (vehicles.meta → Rockstar DLC pack)
    ├── LOD / Streaming Scanner
    ├── Vehicle image tools
    └── Workspace backup / restore

/popcycle.html
└── Popcycle Editor
    ├── DAT import
    ├── 12 AM/PM schedule editor
    ├── visual map editor (4 map modes, zoom/pan, click-to-select area)
    ├── area reference and schedule-to-area matching
    ├── hourly pedestrian and vehicle group weight editor
    ├── batch hour actions (Add/Update, Remove, Apply All)
    ├── police presets (Quiet, Routine, Visible, Heavy, Crackdown)
    ├── traffic presets (Stock Traffic, Street+, City Pulse, Rush Hour, Traffic Redline, Night Shift)
    ├── optional weight rebalancing
    ├── IndexedDB autosave
    ├── Save Workspace / Export Workspace / Import Workspace
    └── export DAT / JSON change report / original backup

/vehicle-meta.html
└── Vehicle.meta Editor
    ├── vehicles.meta import
    ├── traffic field editor (all fields, inline editing)
    ├── quick edit tools
    ├── analyzer (duplicates, missing fields, invalid values)
    ├── saved local files with autosave
    └── export vehicles.meta

/handling-meta.html
└── Handling.meta Editor
    ├── handling.meta import
    ├── profile selector
    ├── per-vehicle handling editor
    ├── numeric increment controls
    ├── AI handling selector
    └── export handling.meta

/vehicle-library.html
└── Vehicle Library
    ├── cloud vehicle list (grid and list views)
    ├── search, filter, sort
    ├── category filters
    ├── library stats (vehicles, images, handling, popgroups, installed)
    ├── import tools (vehicles.meta, handling.meta, Popgroups)
    ├── installed file scanner (YFT/YTD matching)
    ├── installed / favorite flags
    ├── pack membership summaries
    ├── random vehicle selection
    ├── pagination
    ├── Source History panel (recent imports — Step 19E, in progress)
    └── links to vehicle details

/vehicle-details.html?model=<modelName>
└── Vehicle Details
    ├── vehicles.meta data
    ├── handling.meta data (linked by handlingId)
    ├── Popgroups memberships
    ├── Rockstar / GTA Source History (DLC reference packs)
    ├── Mod Pack Membership (add-on/mod packs)
    ├── vehicle image (from R2)
    ├── custom fields (display name, install type, replacement slot, DLC folder, paths, download URL)
    ├── tags and notes
    ├── favorite and installed status (cloud-persisted)
    ├── previous / next vehicle navigation
    └── cloud image upload / replace / delete
```

## Implementation Notes

- Local browser tools (Popgroups, Popcycle, Vehicle.meta, Handling.meta) must remain usable without login.
- Keep "Save Locally", "Save to Profile", and "Admin Publish to Cloud" visually distinct throughout the UI.
- Admin-only cloud controls must be clearly labeled as admin-only.
- All dangerous admin actions require preview/dry-run before execution.
- Prefer archive/disable over hard delete everywhere.
- Pack display belongs inside `vehicledetails.js` — do not use global DOM injectors or MutationObserver scripts.
- Do not expose admin tokens or database credentials in browser code.
- `public/` is the deployed static site source for Cloudflare Workers.
