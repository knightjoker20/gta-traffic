How it works: Each NPC profile (COP, GANG, DEFAULT…) holds a list of response rule names. When an event fires, the game checks matching rules in order and rolls against Chance_SourcePlayer/Friend/Threat/Other to decide which task to assign. Probability 0 = never, 1 = always. The EventResponseDecisionFlags constrain which contexts the decision applies in (on foot, in car, in complex scenario, etc.).
