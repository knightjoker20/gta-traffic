Modding Tools

GTA 5 Modding Resources

The essential tools you need to mod GTA 5 story mode — from opening RPF archives to building custom scripts. All links go to official sources.

New to modding? Start with OpenIV (required for almost everything), then ScriptHook V if you want to run script mods. Use CodeWalker to visually explore the game world. All tools listed here are free unless noted.

Essential — Install These First

📦
OpenIV
by Illusion Softworks / OpenIV Team

The primary tool for reading and writing GTA V RPF archives. Required to install virtually every mod. Use it to browse update.rpf, replace .meta files, and manage your mods folder.

Required Free Windows
🪝
Script Hook V
by Alexander Blade

Enables .asi script plugins in GTA V story mode. Required by most script-based mods (trainers, spawn mods, gameplay overhauls). Must be updated after every GTA V patch. Includes the Native Trainer as a bonus.

Required for scripts Free Windows
📥
OpenIV Enhanced RPF Plugin
OpenIV-Asset-Handler

Extended OpenIV plugin that adds enhanced RPF archive handling, deeper asset inspection, and improved file management. Also known (officially, somehow) as the OpenIV File Management Toolkit, Resource Analysis Workspace and Structured Archive Inspection Environment. Download from GitHub Releases.

Free Plugin GitHub

Editors & World Viewers

🗺️
CodeWalker
by dexyfex

Full 3D renderer for the GTA V world. Browse the map, inspect entity placements, view IPL/ymap files, explore interiors, and edit scenario nodes. Essential for understanding traffic and spawn layouts.

Free Windows .NET required
🧊
Sollumz
by Skylumz et al.

Blender plugin for importing and exporting GTA V model formats (.ydr, .ydd, .yft). The go-to tool for creating custom vehicle models, peds, and map props that work natively with GTA V's renderer.

Free Blender 3.x+ Open Source
🔧
ZModeler 3
by Oleg Melashenko

Long-standing 3D tool with native GTA V export support. Widely used for vehicle modding, especially in the GTA modding community's earlier era. Requires a paid licence for full export functionality.

Paid licence Windows

Scripting Frameworks

🟢
ScriptHook V .NET
by crosire

C# scripting framework built on top of Script Hook V. Provides a high-level API over all of GTA V's native functions. Comes in two flavours: Legacy (original crosire release, widely compatible) and Enhanced (actively maintained fork with expanded API and bug fixes). Most modern script mods require one or the other — check each mod's readme.

Free C# Open Source
🚓
LSPDFR
by G17 Media

Police roleplay modification — turns GTA V into a fully featured police simulator. Also has its own plugin API (RAGE Plugin Hook) used by many traffic and police behaviour mods.

Free Roleplay
🔌
RAGE Plugin Hook
by LMS

Alternative scripting framework used by LSPDFR and its plugin ecosystem. Provides C# access to GTA V internals via a different loading mechanism than Script Hook V .NET — the two can coexist.

Free C#
🍋
LemonUI
by justalemon

C# UI framework for building native-style menus, notifications, and HUD elements in GTA V script mods. Widely required as a dependency by modern C# mods — if a mod's readme says "requires LemonUI", drop the DLL in your scripts folder. Supports ScriptHookVDotNet 3, RAGE Plugin Hook, RageMP, and FiveM.

Free C# Open Source GitHub
📱
iFruitAddon2
by Bob74

Library that lets script mods add custom contacts to the in-game iFruit phone. Used by LSPDFR plugins and ScriptHookVDotNet mods to trigger events via in-game phone calls. If a mod ships with an iFruitAddon2.dll, put it in your scripts folder alongside the mod.

Free C# Requires SHV.NET GitHub

Trainers & In-Game Tools

🎮
Menyoo PC
by MAFINS

Feature-rich single player trainer and object spawner. Lets you spawn vehicles, peds, and props, teleport around the map, edit entity properties, and save/load scenes — invaluable for testing traffic spawns.

Free Requires SHV
🛠️
Simple Trainer
by sjaak327

Lightweight but powerful trainer covering teleportation, weather control, vehicle spawning, time editing, and a suite of developer-useful toggles. Often used alongside Menyoo for its different feature set.

Free Requires SHV
🗂️
Map Editor
by Guadmaz

In-game prop placement tool. Spawn objects, vehicles, and peds at exact world coordinates, then export as XML for permanent map additions. Good for testing scenario spawns in the actual world.

Free Requires SHV.NET

Asset & Ped Tools

🧑
Add-On Peds Manager
by DarthPungz

Manages custom ped (pedestrian) models added to your game. Handles the peds.meta and carvariations.meta entries needed for custom peds to spawn properly in traffic and popgroups.

Free Peds
🎨
GIMS EVO
by 3Doomer

3ds Max plugin for importing and exporting GTA V models. Used by many professional modders for vehicle creation. Requires a 3ds Max licence.

Requires 3ds Max Vehicles
🟢
ScriptHook V .NET Nightly
by scripthookvdotnet

The actively maintained nightly build of ScriptHook V .NET — updated to track GTA V patches faster than the stable release. Use this if the stable build breaks after a game update. Required by the majority of C# script mods.

Free C# GitHub

References & Community

🌐
GTA5-Mods.com
community repository

The main repository for GTA V mods — vehicles, scripts, maps, textures, peds, and more. Use the Vehicles section to browse add-on car packs you can import into this site's Vehicle Library.

Free Repository
📖
GTAMods Wiki
community wiki

The most complete technical reference for GTA V file formats. Covers .meta XML schemas, handling flags, popgroup structure, dispatch internals, RPF layouts, and more. Bookmark this — you'll use it constantly.

Free Reference
💬
GTA5-Mods Forums
community forum

Active modding community forum. The best place to ask questions, get help with specific mod problems, and browse existing solved issues around traffic, dispatch, and vehicle spawning.

Free Community
🎙️
GTAMods Discord
community server

The main Discord server for GTA modding. Real-time help channels covering vehicles, peds, scripts, maps, and native research. Many mod authors are active members.

Free Discord
💬
GTAForums
gtaforums.com

The longest-running GTA community forum. Decades of modding knowledge, dedicated boards for tools, scripts, vehicles, and missions, plus active release threads for major mods.

Free Forum
📡
FiveM Native Reference
docs.fivem.net

The most comprehensive documentation for GTA V native functions. Essential for script modding — every native call, parameter type, and return value is documented and community-annotated. Applies to both FiveM and story mode scripting.

Free Reference
