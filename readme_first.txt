# GTA-Traffic.com Popcycle Visual Map Editor 1.3.0

This full site was rebuilt from the current site archive uploaded on 2026-06-07.

## Main tools

- `index.html` — Popgroups Editor and Vehicle Library
- `popcycle.html` — Popcycle Visual Map Editor

## New in this version

- Zoomable and pannable multi-layer map
- Los Santos district, full-island, regional, and patrol reference views
- Marker clicks that select schedules
- Batch vehicle-group editing across checked hours
- Police presets that also manage `VEH_COPCAR`
- IndexedDB autosave and workspace backup/import
- Integration with saved Popgroups group names
